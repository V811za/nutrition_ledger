Figures are AI-estimated using web-sourced nutrition data (incl. Woolworths SA product info where relevant) — approximate, not medical or lab-grade. The dashed target line on the Weekly/Monthly charts is a standard Mifflin-St Jeor estimate (edit it under the gear icon) — a general starting point, not a prescription. It doesn't account for NAFLD, thyroid replacement therapy, or gastritis; loop in your doctor or a dietitian before committing to a target, since weight change can affect thyroid medication dosing and NAFLD management benefits from gradual, supervised loss. Entries and your API key are stored only in this browser, on this device.

API key

Your Anthropic API key is stored only in this browser's local storage on this device — it's sent directly from your browser to Anthropic and nowhere else. Get one at console.anthropic.com, under API Keys. Each meal lookup uses a small amount of your own API usage.

Calorie target

Used to draw the target line on the Weekly/Monthly charts. A standard estimate (Mifflin-St Jeor), not a medical prescription — see the note under the charts.

Nutrition lookups are cached and reused for 6 months so repeat meals don't re-query the API. Clear cache to force fresh lookups.

Cloud sync

Lets the same log appear on your laptop and phone. Uses jsonbin.io (free, no card needed) as private cloud storage — your entries are stored there, accessible only with the key below. Set this up once, then enter the same API key and Sync ID on every device.
